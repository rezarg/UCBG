## Untitled Circuit Building Game (UCBG)
[UCBG](https://polytoria.com/places/140234) is a game made on the [Polytoria](https://polytoria.com) platform.

There is a community-managed Wiki here: https://polyucbg.miraheze.org/wiki/Main_Page <br>
You can join the official Discord server here: https://discord.com/invite/d2c8TZCR62

### Contributions & Licensing
UCBG is open to contributions, and encourages users to make Pull Requests! <br>
Use StyLua for contributions to keep formatting as consistent as possible.
